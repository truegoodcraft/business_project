# BUS Core v1.3.2 Release Notes

Date: 2026-06-20
Tag: `v1.3.2`

## Summary

BUS Core 1.3.2 is the LazoralltheCore / Laser Everything Community Polish Patch. It closes first-look and tester friction across the first material-to-product workflow while preserving Core's local-first, open-source trust boundary.

## What Changed

- Clarified Product, Recipe, and Output Item/Output Product wording so operators can distinguish the inventory item being built from the recipe that builds it.
- Stock-out sale price now starts from the selected product price where available, shows the usual price, and warns non-blockingly below the usual price.
- Made manufacturing and stock-out shortage messages human-readable with item names and need/have/missing quantities.
- Manufacturing history now displays run labels as `Run #N`.
- Added Finance date presets for Last 30 days, this month, last month, this quarter, last quarter, and this year.
- Strengthened Start Fresh and demo safety copy so operators know demo data is separate and real-shop data should be backed up first.
- Fixed backup/restore SQLite URI handling for Windows paths containing spaces or `#`, with regression coverage for export, preview, and restore commit.
- Reconciled the `/dev/writes` CORS/session test contract with its intentionally hardened behavior without weakening runtime guards.
- Fixed route/security test isolation so module reloads and synthetic app state no longer make combined security suites order-dependent.
- Updated release metadata, Home's Latest Update card, cache-busting tokens, and governed version mirrors for v1.3.2.

## Stability Focus

Core is now feature-frozen and stability-focused. BUS Core remains maintained local-first, open-source infrastructure with no forced cloud and no telemetry.

Future Core updates will focus on bug fixes, safety, security and trust, backup/restore and data protection, tester blockers, update/release reliability, small UX clarification, and documentation. New major workflow or domain expansion moves to BUS Pro discovery.

## Still Not Included

BUS Core does not include:

- Full POS
- Full accounting
- QuickBooks/Wave sync
- Automatic reorder
- Full job scheduling
- Cloud accounts
- Cloud sync
- Telemetry
- Payment links
- Customer portals
- Recurring billing

## Trust Boundary

- No runtime auth, CORS, write-gate, local-only, backup/restore authority, update authority, or security-posture weakening is part of this release.
- Core remains usable locally without a hosted account or forced cloud dependency.
- This release does not claim new signing or update-verification behavior.

## Owner Release Guardrail

Build and sign only after this version bump is committed on the default branch. Create and publish tag `v1.3.2` only when it resolves to the current default-branch release commit; the release mirror validates the tag against canonical `VERSION` before mirror/upload work.
