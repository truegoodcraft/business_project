# BUS Core v1.4.0 Release Notes

Date: 2026-07-13
Expected tag: `v1.4.0`
Expected artifact: `BUS-Core-1.4.0.zip`

BUS Core 1.4.0 is a bounded truth-and-release-gate maintenance release. It does not add a product domain or redesign the UI.

## Correctness and authority

- Enforces one non-void invoice per job, including concurrent requests and manual relinking.
- Makes invoice note lines non-financial and prevents cleared quantities from retaining stale subtotal or tax.
- Keeps item metadata from mutating stock; batches, movements, and the inventory journal remain the quantity authority.
- Rejects negative and non-finite item, job, invoice, purchase, and sale prices before partial mutation.

## Release confidence

- Runs isolated API tests through the production lifespan and canonical schema bootstrap with one coherent module graph.
- Ships current privacy, telemetry, update, and SOT truth without stale duplicate API/changelog authorities in `license/`.
- Adds focused regression coverage for every repaired invariant and retains the collision-safe serial release gate.
