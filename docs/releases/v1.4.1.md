# BUS Core v1.4.1 Release Notes

Date: 2026-08-03
Expected tag: `v1.4.1`
Expected artifact: `BUS-Core-1.4.1.zip`

BUS Core 1.4.1 is a bounded update-evidence and release-integrity maintenance release. It does not add a product domain or expand the telemetry payload.

## Update checks and product signals

- Makes the sidebar startup controller the single automatic update-check owner while keeping manual checks available in Settings.
- Applies saved startup-check policy, deduplicates automatic checks per launch, and reports whether a check was performed, its source, and any skip reason.
- Completes queued telemetry and one-time milestones only after Lighthouse acknowledges the exact event ID.
- Retains rejected or retry-exhausted events in a bounded local dead-letter file and exposes only aggregate delivery diagnostics.
- Removes module-open, active-day, returning-installation, session, engagement, retention, and persistent-installation-identifier signals.
- Limits outbound product evidence to first launch, once-per-version adoption, update outcomes, reliability, and one-time successful use of major product areas.

## Release confidence

- Fails the Windows build immediately when runtime/build dependencies are missing or PyInstaller exits unsuccessfully.
- Requires the complete PyInstaller onefile CArchive before artifact copying, signing, or bundling.
- Verifies pre-signing and post-signing launch behavior, artifact hashes, ZIP structure, and the embedded runtime contract.
- Keeps the documented and CI `pytest -q` gate collision-safe while excluding Git-ignored local tools from source-policy scans.
- Uses the deployed and production-verified Lighthouse 1.27.0 receiver with migration 0015.

## Release control

The owner selected public version `1.4.1` and reset the internal revision to `1.4.1.0`. This preparation does not create a tag, build or sign an artifact, publish a release, deploy, or alter another repository. Build and sign only from the exact validated release commit after it reaches the required default/release branch.
